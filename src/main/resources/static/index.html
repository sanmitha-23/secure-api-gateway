Security at the API boundary.

A Spring Boot API gateway demonstrating practical security controls, request validation, authentication, rate limiting, and application monitoring.

Explore the code Try the live API Health status

Security features

JWT authentication

Stateless authentication for protected API routes.

Input protection

Canonicalization and pattern-based detection of suspicious SQLi and XSS input.

File validation

File size, extension, and content-type checks using Apache Tika.

Rate limiting

Redis-backed fixed-window request limits.

Monitoring

Prometheus metrics and a Grafana dashboard for security events.

Containerized setup

Docker Compose runs the gateway with Redis and monitoring services.
